# agentSkills

Self-made Agent Skills for repeatable research and other workflows.

## Skills

| Skill | Purpose |
| --- | --- |
| [Clinical Trial Research](skills/clinical-trial-research/) | Research clinical trials from a biostatistician's perspective, with traceable sources, protocol history, statistical plans, and attributed results. |

Each skill lives in its own folder under `skills/`. Open its README for installation and usage instructions. The clinical trial skill includes English instructions, a Chinese reference edition, and installation guidance for Codex, Claude Code, and Gemini CLI.
