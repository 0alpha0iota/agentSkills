# Clinical trials research

从生物统计师视角调研临床试验，聚焦试验统计学及其关联内容。按下述用户方法组织研究与展示，用统一的执行规范保证证据可追溯、版本清楚、计划与实际分开。当次用户明确指定的范围、格式与方法调整优先。

## 研究原则

- 陈列有来源的事实，不自行判断试验优劣、疗效成败、安全性是否可接受或开发价值。试验结果的解释与小结尽量准确转述研究者或 sponsor 的 conclusion/discussion、公告或 slides，明确主体与日期。严谨性体现在核验与准确表述，不转化为自行评价。
- 根据具体试验的阶段、设计、可用资料灵活调整研究深度与呈现形式；保持适用的核心模块，对缺失或不适用内容说明状态与原因。
- 以独立试验为单位管理证据。建立试验别名、注册号、sponsor trial serial/protocol number 的映射；同一试验的多篇论文、队列、扩展随访和不同数据截点保持关联，不重复计为独立试验。系列试验可在同一 chat 研究，各试验仍单独标识。
- 严格分开初版方案的计划、后续方案修订、最终统计计划与实际实施/结果。不同来源、队列、分析人群、终点、时间窗和数据截点之间的差异分别保留，不拼成无来源的统一数字或结论。
- 所有实质性事实关联明确来源与时间语境。可做有依据的设计标签归类、术语解释和透明的核对计算；标明其属于来源原述、研究者/sponsor 解释、提取归类或研究辅助计算。设计归类不得变成对试验结果的独立判断。
- 默认中文汇报，保留便于核对的英文术语、正式名称和缩写；遵从用户另行指定的语言及交付形式。

## 两种任务入口

### 已指定单项或系列试验

利用试验名称/代号、NCT number、药物名称与分期等识别信息锁定对象，核实唯一性。信息足够时直接开始；存在会改变研究对象的歧义时，先给出候选及差异，再请求必要澄清。随后逐项执行下述九步研究。

### 疗法、适应症或筛选范围内的试验搜索

先做广域搜索与清单交付，用户通常在同一 project 下为每项/系列试验另开 chat 启动深入研究。

1. 将用户条件转为明确的纳入范围、排除条件和检索截止日期；对影响名单的未定条件注明采用的解释。覆盖注册平台、论文及 sponsor 来源，结合适应症/疗法同义词、药物别名、开发代号和注册编号迭代检索，保留查询式和覆盖边界。
2. 核对身份并去重。交付表至少含：试验代号/名称、注册号与 sponsor serial number、主要 sponsor、药物/疗法、研究适应症/人群、分期与基本设计、状态及其更新时间、符合条件的依据、关键来源。资料不确定者标记为待核实，不静默纳入或排除。
3. 记录检索日期、信息截止日期、已覆盖来源、筛选规则和重要排除/身份疑点。分页、检索上限或不可访问来源影响覆盖时明确说明，不宣称已穷尽全部试验。
4. 为列表中每一项试验提供可独立复制的启动 prompt；包含技能名称、已核实识别信息、主要来源链接、研究范围、时间截点、项目根目录以及该试验独立的资料/交付目录。各 prompt 的试验目录以不同 study-key 区分，不能把同一个项目公共目录直接作为多项试验的资料/交付目录。序列/系列合并提示须说明包含的独立试验及原因，并在内部保持试验标识。
5. 默认交付到此，等待用户另行启动单项研究；本次不自动深挖整张名单，也不自动创建或消息通知其它 chat。只有用户另外明确要求时才执行相应动作。

启动 prompt 的结构示例（交付时把方括号替换为该行的真实信息，未核实字段注明状态）：

```text
使用 $clinical-trial-research，从生物统计师视角完整研究以下试验：
名称/代号：[名称]；注册编号：[编号]；sponsor trial serial/protocol number：[编号或未查到]；主要 sponsor：[名称]；药物/疗法：[名称]；研究适应症：[范围]。
已核实入口：[注册记录、论文、sponsor 资料链接]。
研究范围与信息截止日期：[范围、日期；未指定固定历史截点则截至本次检索日]。
项目根目录：[已知的绝对目录]；本试验资料目录：[含本试验 study-key 的独立绝对路径]；交付目录：[含本试验 study-key 的独立绝对路径]。新 chat 无法访问时，在其工作区建立本试验独立目录并说明路径。
按该 skill 的九步流程调研；区分初版计划、方案修订、最终统计计划与实际结果，只陈列事实，结论注明研究者或 sponsor 的归属。请求协助下载资料时给出准确保存目录。
```

## 本地落地与证据管理

### 启动记录及目录

确定研究对象、范围、信息截止日期和本次检索日期。默认截至本次检索日；历史复盘若限定“当时可知的信息”，以当时公开可获得的材料为准，后续材料须另列且说明不属于该历史信息集。文件获取日、发表日、文件版本日和结果数据截止日分别记录。

优先使用用户指定的工作目录并遵守当前 project 的约定。用户只指定项目公共根目录时，为各试验建立独立子目录；已明确指定单项试验专用目录时直接沿用，不重复嵌套。没有约定时，资料根目录使用 `<workspace>/work/clinical-trial-research/<study-key>/`，交付目录使用 `<workspace>/outputs/<study-key>/`；领域搜索使用独立的 `<search-key>`。`study-key` 优先用注册号，无注册号则用核实后的试验代号。向用户说明解析后的绝对路径，不写入技能安装目录，也不硬编码某次会话的路径。已有文件先检查并增量补充，保留既有版本。

按需建立以下最小结构；没有相应材料时不建立空目录：

```text
<study-root>/
  sources/                 原始下载材料，按 registry、protocols、saps、publications、sponsor、supporting 分目录
  incoming/                用户协助下载后放置材料的目录
  extracted/               文本、结构化表格、关键摘录及核对计算
  figures/                 原图截图、流程图/时间轴源文件与渲染图
  search-log.md            查询、日期、覆盖范围与检索结果
  source-register.tsv      来源目录，含文件版本和获取状态
  evidence-ledger.tsv      关键字段/结果与原文定位的对应关系
  issues.md                待取资料、冲突、缺失与处理记录
<deliverable-root>/
  research-report.md       九步报告；领域搜索时改为试验清单及逐项启动 prompts
  figures/                 报告引用的最终图件（如有）
```

报告采用用户要求的格式；未指定时以 Markdown 为主，不默认额外制作 PDF、Word、slides 或网站。原始资料与提取文件分开；以来源类型、版本/日期、短标题命名文件，来源目录登记实际文件名。重要原件可记录校验值以识别更新或重复下载。

### 资料获取与来源真实性

主要来源是三类，按所回答的问题选用，不能用机械的总排序替代逐项核对：

| 来源 | 主要用途 | 必须关联的材料 |
| --- | --- | --- |
| ClinicalTrials.gov 等注册平台、相关监管网站托管资料 | 身份、注册历史、设计及预设计划 | protocol、SAP、修订记录和附件；注册记录本身与托管原件分开标识 |
| 试验 publications，PubMed 等为检索入口 | 实际实施、参与者、基线、分析与结果、研究者解释 | 正文、补充材料、附录、更正及相应随访/亚组报告 |
| Sponsor 官方网站公告、pipeline 资料和成果展示 slides | 官方开发信息、补充结果、sponsor 自述 | 公告日期、会议/汇报日期、slide 页码与对应数据截点 |

通过注册号、trial serial number、正式标题、sponsor、干预与设计等相互核对资料归属；有注册号时优先精确匹配，无编号时组合核对多个独立识别字段。不能只因药名或标题相似就认定为同一试验。核实发布主体、原始链接、正文标识和版本信息；辅助来源也执行相同核验。PubMed 条目、搜索摘要或新闻转述不能冒充已核验的全文/原件。

用注册号、全部主要别名和 sponsor serial number 搜索三类渠道；追查 protocol/SAP 的历史版本、附录与论文 supplements，特别寻找初版方案、最终方案及最终 SAP。新颖方法的解释另检索原始方法论文或正式方法文献，不将其它试验的统计计划套用到本试验。工具/站点变化时查看当前官方说明，不把固定工具名或旧 API 写成执行前提。

有价值材料无法获取时，先尝试合理可用的正式替代入口；仍受阻则向用户集中列出文件标题、所需版本、原始链接、用途、阻碍及**准确的绝对保存路径和建议文件名**。先建立对应 `incoming/` 目录；用户提供后按同样标准核实归属与版本、登记来源，并复制/归档到相应 `sources/`。继续完成不依赖该材料的研究，将受影响模块明确标记为待补。

### 来源记录、字段记录和冲突处理

- `source-register.tsv` 每条记录至少含：source ID、试验/队列、资料类型与标题、发布者、URL/DOI/PMID/注册号、文件版本、原文标注日期及日期类型、发布/上传日（可查时）、获取日、本地文件路径、结果数据截点（适用时）、归属核验依据与获取状态。
- `evidence-ledger.tsv` 对关键字段、人数、终点、统计方法、结果和图件记录：字段/结论、值及单位、所属试验/队列/人群/时间窗、计划或实际、版本/分析截点、source ID、章节/表/图/页码、原文片段、复核状态。数值型结果保留分母、效应方向和置信水平。
- 报告段落、表行及图注就近给出来源链接与定位；PDF 区分印刷页码与文件页序，slides 标页码，网页标章节与日期。不能只在报告末尾堆放无法对应具体事实的参考资料。
- 原件缺失、未检索到、已发现但无法访问、原文未报告、版本无法确认、不适用分别标记；未经证实不写“没有 SAP”“不存在修订”或“从未开展分析”。
- 冲突先检查来源版本、队列、分析集、单位、时间窗与数据截点；可解释则并列说明。仍无法解释时保留双方值及定位，在 `issues.md` 记录，不默选一个数字。无第二来源时可复核原件上下文并注明“仅单一来源可核实”，不能声称已独立交叉验证。

## 单项试验的九步研究与报告

正式报告默认依次包含以下九步。每步给出相应事实、来源和必要的缺口说明，不能以通用临床综述替代。对于未出结果或提前终止的试验，保留适用部分并说明尚未公开的结果。

### 第一步：汇总试验识别信息

列出试验代号（如有）/名称、trial serial number（sponsor protocol/study number）、注册信息（一般 NCT number，兼列其它注册号）、主要 sponsor、药物/疗法名称及别名、注册研究适应症。区分注册研究适应症与获批适应症；明确多部分/系列研究的关系，缺失编号不自行生成。

### 第二步：适应症与作用机制简述

简述适应症病理原理，以及药物成药机制/疗法作用机制。按适用情况说明药物类型（ADC、抗体药、核酸药、小分子等）、靶点、作用方向（抑制、拮抗、激动等）和与研究场景的关联。篇幅服务于生物统计师理解人群、设计和测量，不扩展为独立的疾病或商业综述；机制事实也需来源。

### 第三步：分期、性质与基本设计

给出精炼设计标签与简述，按适用性涵盖 Phase、干预性质、盲法、随机化、对照类型、中心设置、分配比例、parallel/crossover、单臂/多臂、dose-escalation/expansion、多阶段或自适应安排等。标签从 synopsis 与 protocol 全文综合提取，并注明对应版本；如 Simon two-stage、双盲后转开放标签等须明确阶段关系。标签归类引用支持该归类的具体设计，不把缺乏原文依据的推测写成确定事实。

### 第四步：研究人群与最终方案的入排标准

先简述研究人群，再按 **final protocol** 完整呈现详细 inclusion/exclusion criteria，保留关键阈值、检测方法、时间窗、既往治疗要求及例外；必要时附原文。标明版本及 final 的依据。最终方案的规定与实际执行保持区分；实际执行差异放入第八步。

### 第五步：初版 protocol 的计划试验流程

以**真正初版 protocol** 为依据，先文字简述，再绘制 flow chart，覆盖 screening/enrollment 至试验结束及相关 follow-up。

- 通常从左至右表示早期至后期；按 arms/cohorts 分支或分泳道，按阶段分段。
- 只标计划人数并区分组别/队列，不混入实际参与者流向。计划人数未分配到具体组时说明，不能按分配比擅自补数。
- 标出适用的 screening、入组、随机、治疗/观察阶段、计划期中分析、阶段推进规则、EOT 及 follow-up 时段，保留关键时间长度与条件。
- EOT、EOS 等缩写按本试验原文释义使用，核实其指治疗结束、试验结束还是研究结束；不要自动等同，也不要遗漏治疗后随访。
- 图题及图注明确“初版方案的计划流程”、版本、日期与来源。这是设计时的计划，不预示实际走向。

原始方案不可得时明确写“初版 protocol 未取得，不能完整确认初始计划”。可以另绘**最早可获得版本的计划流程**或**注册历史所载计划的局部重建**，但必须显著标明依据、版本及缺失部分，不能命名为“初版 protocol 流程”，也不能凭最终方案或结果倒推原始流程。

### 第六步：Protocol revision timeline

聚焦核心临床开发决策或对统计分析有重大影响的 amendments，例如目标人群、剂量/治疗组、队列和样本量、研究阶段/流程、objectives/endpoints、观察期或分析安排的变化。小修订可保留在资料索引中，时间线不堆砌文字性更正。

先制作修订表：版本号、版本/生效日期及日期类型、核心修订内容、原文披露的修订原因、来源定位。原因未披露就注明；不能因 AE、机构沟通与 amendment 时间接近而自行建立因果。日期只有签署日/版本日时按原类型呈现，不能当成已确认生效日。

再作最初版与 final protocol 的逐项对照，覆盖 treatment、分组、剂量、队列数与规模、总样本量、观察/治疗期、访视、试验设计/流程及适用的目标/终点；用“原版—最终版—证据”展示。版本缺失时说明实际对比的是哪两版。

最后制作带坐标轴的时间线可视化，按时间顺序标注初版、最终版及主要 amendment 的版本号、日期与简要内容，加入最终 SAP 的版本/日期、锁库及相关期中分析数据库冻结日期。尽量按真实日期比例排布；仅有年月或日期缺失时显示精度/未知，不制造准确日期。事件过密可交错标注。

分别记录 SAP 签署/版本日期、修订日期、冻结/锁库日期和公开上传日。若有证据表明最终 SAP 在冻结/锁库后发生变更，标出变更日期、具体内容与原文披露的原因；材料只显示 SAP 日期较晚时，仅报告可确认的时序及缺口，不自行认定分析计划为事后制定。多个期中/最终数据截点分别对应，不混成一次锁库。

### 第七步：预设目标、终点、样本量与统计分析

主要从 **final SAP** 提取，用 **final protocol** 复核。SAP 不公开或无法取得时，从 final protocol 提取，并用 publications/补充材料等核实；明确来源替代和仍缺失的部分。计划与发表分析不一致时分别展示，不能把论文中实施的方法无条件写成预设方法。

1. **Study objectives & endpoints**：对应呈现 primary、secondary、exploratory objectives 与 endpoints，primary 优先并保留关键次要终点。对每个研究终点简述测定方法/量表、数据类型、单位、评估时间窗和临床含义；适用时保留判定标准、评估主体、事件定义与汇总方式。目标与终点不机械一一配对，按来源关系呈现。
2. **样本量估算与 statistical assumptions**：提取计算方法、主要参数、假设、显著性水平及单/双侧、power、预期效应/率/变异度、分配比、脱落或不可评估调整、事件数/入组与随访假设、阶段/队列样本量及停止/扩展规则（按设计适用性取舍）。缺失参数保持缺失。必要的复算另列输入、公式、代码/方法及差异，不能替代原文计划或修改其假设。
3. **重点预设分析**：按主要终点、关键次要终点及其它重点分析对应说明主分析框架、分析集、组间检验、效应量及其估计/区间报告方法；再列适用的敏感性分析、缺失数据处理、亚组及交互作用分析、多重性控制、期中/序贯检验与阈值。适用时记录 estimand、intercurrent events、协变量、删失及模型假设，保持与终点和计划版本关联。
4. 新颖或复杂方法提供额外的针对性解释及可核验的方法学参考文献，区分“该试验确实采用”的证据与“方法如何运作”的参考来源。没有亚组/多重性安排的可核实资料时标注来源未报告，不自动断定没有该安排。

### 第八步：实际实施与试验结果

主要取自对应 publications 及 supplements，结合 sponsor 官方公告/slides 和其它经核实的该试验资料补充。对每份结果标明报告日期、数据截点、随访长度及分析人群；更新报告保持可区分。

**先说明实际实施。** 陈列实际 screening/enrollment、入组人数、随机/队列、接受治疗、退出、完成与分析集等可得信息，提供参与者流向；可沿第五步的图形规范另绘实际流程图，使用准确人数及已报告的关键事件日期。未知人数/日期标缺失，不从计划推算。针对适用阶段说明访视与 follow-up。人数应按阶段、组别及人群定义核对，不把不同口径硬凑成总和。

**再交代人群与基线。** 以 final protocol 的实际执行版入排规定作 in-a-nutshell 摘要；如果只能确认最终方案规定，明确其证据范围，不能声称该版本在整个招募期均执行。结合论文陈列可证实的实际适用标准、访视/随访和与方案的差异。提取 baseline characteristics remarks 及 baseline characteristics summary table，保留各组 N、单位、统计量形式、缺失值和原表脚注；不自行用基线差异对随机化质量下结论。

**随后汇总核心结果。** 根据试验采用“主要—次要指标”或“有效性—安全性”结构，始终将 primary 与 key secondary endpoints 放在最高展示优先级，保留结果不利、未达预设标准或未公开等事实状态，避免只摘 sponsor 强调的结果。安全性按适用人群、暴露、AE 分类/分级、严重性与分母保留原文口径；缺乏对照时不自行作比较判断。

结果表按需要包含：终点/时间窗、分析人群与 N、各组结果或事件数、effect size 及方向/参照组、95% CI、p-value、使用的检验/模型、数据截点与来源。保留原文精度、p 值的精确值或不等号、单/双侧及名义/调整后的含义。未报告 p 值或效应量就明确注明，不补造；来源只给其它置信水平时忠实报告并标出水平，不能无依据换算为 95% CI。

若有预设序贯检验链/多重性策略，按实际执行顺序显示每一环的假设、阈值、p 值及来源所述的通过/停止状态，区分正式可检验、未进入正式检验和描述性/名义结果。未披露的实际执行环节标未知，不把所有名义 p 值视为已通过多重性控制。

截取 publications 或 sponsor slides 中支持核心结果的相关图表，并保留标题、图例、坐标、必要脚注和来源页码；记录对应人群与截点，放在相关结果旁。无法取得图表原件时说明，必要时据已核实数据转录/重绘并明确标注，不伪称原图。复建图表不能补入原文未提供的数据，也不从图片估计数值后当作精确报告值。

### 第九步：研究者与 sponsor 的小结

准确引用或转述 publications 的 conclusion/discussion，或 sponsor 的公告/slides。逐段注明发言主体、来源与日期；研究者与 sponsor 的表述不一致时并列呈现。将其解释与前述客观数据分开，不把宣传性表述改写为助手认可的事实，不另加试验成败、疗法优劣、临床推荐或投资判断。引用保持必要且简短，较长内容用忠实转述。
